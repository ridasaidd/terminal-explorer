WEEK 1 — ARRIVAL

Blackthorn Manor is a real Linux directory tree.
You will explore it using real Linux commands.

The adventure begins here:

~/terminal-explorer/manor/ground_floor/entrance_hall

Enter the room:

cd ~/terminal-explorer/manor/ground_floor/entrance_hall

Then read what is there:

cat clue.txt

Week 1 focuses on navigation and orientation.

Remember these four landmarks:

.    here
..   parent directory
~    your home directory
/    filesystem root

You will also learn three useful ways to describe a destination:

relative path   = directions from where you are now
absolute path   = complete address beginning at /
home-based path = directions from home beginning with ~

Commands introduced in this week:

pwd      show your current location
ls       list what is nearby
cd       move to another directory
cat      read a text file
clear    clear the terminal screen
history  show commands you have already typed

You do not need to memorize everything before starting.
The manor will give you reasons to use each idea.

Some passages are symbolic links. In the manor they behave like portals.
You can use them before you learn how to create them yourself.
