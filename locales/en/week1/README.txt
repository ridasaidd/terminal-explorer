CHAPTER 1 — ARRIVAL

Blackthorn Manor is a real directory tree.
You will explore it using real Linux commands.

The adventure begins in:

~/terminal-explorer/week1/mansion/entrance_hall

Enter the room:

cd ~/terminal-explorer/week1/mansion/entrance_hall

Then read what is there:

cat clue.txt

Commands introduced in this chapter:

pwd   show your current location
ls    list what is nearby
cd    move to another directory
cat   read a text file
clear clear the terminal screen
history show commands you have already typed

You do not need to memorize them all before starting.
The manor will give you reasons to use them.
