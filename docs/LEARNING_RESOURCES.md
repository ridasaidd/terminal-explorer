# Learning Resources

Terminal Explorer keeps its in-game explanations short so the terminal remains the center of the experience.

When you want a conventional explanation, examples, or a broader Linux reference, use the resources below and then return to the manor.

## Primary companion reference

### freeCodeCamp — Learn Linux for Beginners: From Basics to Advanced

https://www.freecodecamp.org/news/learn-linux-for-beginners-book-basic-to-advanced/

This long-form guide covers Linux from beginner concepts through more advanced topics and is a useful companion to Terminal Explorer.

Terminal Explorer uses external resources as references and curriculum inspiration. Their article text is **not copied into this repository**. Follow the link to read the original source.

## How to use references while playing

If an encounter introduces a Linux concept that does not make sense yet:

1. Read the room or clue again.
2. Try the provided hint if one exists.
3. Use `man <command>` when you are ready to read Linux's own manual pages.
4. Consult the companion reference above for a longer explanation.
5. Return to the terminal and solve the situation yourself.

The goal is not to memorize every command. The goal is to learn how to explore, reason, and find reliable information when you need it.
